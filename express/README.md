📖 프로젝트 개요
이 프로젝트는 Trello/Asana 스타일의 프로젝트 관리 플랫폼 백엔드입니다.

Express + TypeScript를 사용해 서버를 만들고,

OOP(객체지향 프로그래밍) 구조로 확장 가능한 설계를 적용합니다.

MongoDB + Typegoose를 사용해 데이터를 관리하며,

2025 최신 기술과 고급 패턴을 적용해 실무급 아키텍처를 구현합니다.

🎯 목표
A~Z까지 백엔드 설계 경험

기초 Express → 고급 OOP → 실무 패턴 → 최신 기술 적용까지 전부 학습

OOP 기반 계층형 아키텍처

Controller → Service → Repository → Domain 구조

확장성과 유지보수성 높은 서버

사용자(User), 작업공간(Workspace), 프로젝트(Project), 태스크(Task) 설계

MongoDB 최신 기능

Transaction, Change Streams, Typegoose를 통한 타입 안정성

🛠️ 기술 스택
Language: TypeScript

Framework: Express

Database: MongoDB (Typegoose)

Architecture: OOP + Layered Architecture + Clean Code
